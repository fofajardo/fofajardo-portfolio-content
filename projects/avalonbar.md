AvalonBar is a sidebar with the aim of reimplementing and expanding upon the features and concept of the Longhorn Sidebar. This project is a fork of LongBar from CodePlex.

It features 9 default themes, tile addition from the Tile Gallery, taskbar expansion capability, run-at-startup option, blur-behind effects on Windows 7 and 10, and multi-monitor display selection.
